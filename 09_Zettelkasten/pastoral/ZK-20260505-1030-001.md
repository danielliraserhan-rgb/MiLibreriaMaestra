# Conocer el principio y el final para saber cómo participar — el comienzo sin el fin produce solo simpatizantes

No basta conocer el comienzo — nacer de nuevo, recibir a Cristo. Hay que conocer también el final para saber cómo participar. Sin la meta el discipulado se convierte en simpatía religiosa.

El comienzo y el fin juntos definen la carrera.
