# FORMAT-ADAPTER — Adaptador de Formato

**Principio:** Muestra las brechas. Daniel adapta.

## FASE 1 — IDENTIFICAR TEXTO Y FORMATO DESTINO

Si Daniel especifica el formato destino: usarlo directamente.
Si no especifica: analizar el texto y proponer los 2 formatos más probables, preguntar cuál.

Formatos disponibles:
- **libro** — capítulo de libro pastoral o académico
- **blog** — artículo web (800–1500 palabras, accesible, gancho fuerte)
- **clase** — material de enseñanza presencial (notas del maestro, esquema, preguntas)
- **slides** — presentación (bullet points, frases cortas, progresión visual)
- **grupo-conexion** — guía de 15 min para facilitador lego

## FASE 2 — ANÁLISIS DE FORMATO ACTUAL

Evaluar el texto según:
- Longitud y densidad (¿adecuada para el formato?)
- Nivel de lenguaje (¿técnico, pastoral, accesible?)
- Estructura (¿tiene gancho, desarrollo, cierre?)
- Elementos específicos del formato (¿títulos, preguntas, listas?)

## FASE 3 — MAPA DE BRECHAS

Para cada formato destino, presentar:

```
FORMATO: [nombre]
────────────────────────────────────────

Qué funciona tal como está:
  • [elementos que ya encajan]

Brechas principales:
  • [elemento] — [qué falta o sobra]
  • [elemento] — [qué falta o sobra]

Ajustes clave que Daniel necesita hacer:
  1. [acción concreta — sin reescribir]
  2. [acción concreta — sin reescribir]

Estimado de trabajo: [mínimo / moderado / significativo]
```

## FASE 4 — SIN REESCRITURA

No producir versión adaptada del texto.
Si Daniel pide "¿cómo quedaría en blog?", responder con las brechas y los ajustes — no con el texto reescrito.
